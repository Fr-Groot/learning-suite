Create your e-learning modules, no subscription

Learning Suite is a set of tools to design, produce, review and share online training. Its editor, Studio, builds modules as slides or in a vertical phone format, with graded exercises and practice activities, then exports them as SCORM or as an HTML5 site.

What Studio already does

A simple editor: click a block, place it with the mouse, edit its content on the right. What you see is exactly what the learner will see.

🖥️

Two formats

16:9 slides with freely placed blocks, or a scrolling vertical format, ideal on a phone.

🧩

Page templates

Title + text + image, two columns, quote, question, result… A ready page in one click.

🔊

Voice-over and media

Images, videos, sounds, a voice-over per page with transcript, and a “Next” button that waits for the end.

📦

SCORM 1.2 and HTML5 export

Score, pass/fail and resume sent to your LMS. Tested in SCORM Cloud. Or a standalone site, no platform needed.

🎮

AI-made HTML games

Drop in a game generated by an AI: it runs in an isolated frame and sends its score to the module.

🌍

English and French

The editor and the modules speak English or French. Undo / redo, automatic saving.

Exercises and activities

Two clear families. Exercises are graded and count in the score sent to the LMS. Activities are never graded: learners discover, practise and reflect. Everything works by touch, mouse and keyboard.

Roadmap

The target workflow, every step optional: framing → script → storyboard → production → review → delivery.

  1. Format, player and export done

    Open, documented module format, HTML5 player, SCORM 1.2 and HTML5 export validated in SCORM Cloud.

  2. Exercises and activities done

    Quizzes, fill in the blanks, drag and drop, areas, flip cards, tabs, timeline, HTML games; partial or all-or-nothing scoring.

  3. Studio, the core editor done

    Pages, templates, mouse-placed blocks, properties, theme, voice-over, preview, export; English and French.

  4. Release in progress

    Public code, installers built by GitHub, free code signing via SignPath Foundation, first download.

  5. Learning Suite launcher in progress

    Recent projects, workflow stage, suite apps, favourite tools (including Clicksy and its actions).

  6. Studio: editing exercises and activities

    Questions, answers, areas drawn with the mouse; new exercises and activities; import from Clicksy.

  7. Design workflow

    Framing, script and storyboard, then pages created in one click; storyboard export for client sign-off.

  8. Review

    Review package opened in the browser, comments with screenshots, imported into Studio.

  9. Claude and integrations

    Studio driven by Claude (MCP), “Edit with…” (ArtCraft, Krita…), free offline voice-over, sharing as a link.

FAQ

Is it really free?

Yes, completely, with no limit on modules. The project is open source and relies on no paid server.

Do I need a learning platform (LMS)?

No. The HTML5 export gives a standalone site to put online or open from your PC. If you have an LMS (Moodle, Chamilo, Rise Up…), the SCORM 1.2 export sends score, pass/fail and resume.

Which systems?

Studio runs on Windows 10 and 11. Exported modules open in every recent browser, on computers, tablets and phones.

When can I download it?

The first public version comes with the signed installers. Watch the GitHub repository to be notified.

Can I use games or content made by an AI?

Yes: an HTML page generated by an AI can be inserted into a module. It runs in an isolated frame and can send back a score.
